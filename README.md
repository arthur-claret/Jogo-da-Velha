## Sobre o projeto

Este é um projeto pessoal, feito por hobby, com o objetivo de praticar lógica de programação em C. É uma implementação do clássico **jogo da velha**, jogada diretamente no terminal, com navegação pelo tabuleiro usando o teclado.

## Funcionalidades

- 🎮 Tabuleiro 3x3 renderizado no terminal
- ⌨️ Navegação pelo tabuleiro com `W`, `A`, `S`, `D`
- ✅ Seleção de posição com a tecla `Q`
- 🔄 Alternância automática entre os jogadores (X e O)
- 🚫 Bloqueio de movimento para posições já ocupadas

## Como jogar

| Tecla | Ação             |
|-------|------------------|
| `W`   | Mover para cima  |
| `A`   | Mover para esquerda |
| `S`   | Mover para baixo |
| `D`   | Mover para direita |
| `Q`   | Marcar a posição atual (X ou O) |

O jogo alterna automaticamente entre o Jogador 1 (X) e o Jogador 2 (O) a cada jogada.

## Tecnologias utilizadas

- **Linguagem C**
- Biblioteca `conio.h` (captura de tecla sem precisar pressionar Enter)
